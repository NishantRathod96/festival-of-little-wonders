# The Festival of Little Wonders ✦

A royal-purple, interactive Diwali Padwa experience. Explore five stars, collect five wishes, and reveal a personalised finale.

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html`.
4. Use Live Server (recommended) or open the file directly in a browser.

No build tools, packages, backend, or API keys required.

## Personalise
Edit `index.html` to change the name and final greeting.
Edit the `wishes` array in `script.js` to change the five wishes.

## Free deployment using GitHub Pages
1. Create a public GitHub repository named `festival-of-little-wonders`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Go to Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/(root)`, then Save.
5. Wait for deployment. The URL will be `https://YOUR-USERNAME.github.io/festival-of-little-wonders/`.

Test the published URL on a phone before sharing. Google Fonts requires internet; fallback fonts are provided. The site does not collect or transmit visitor data.
